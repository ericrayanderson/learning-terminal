# Learning Terminal

https://ericrayanderson.github.io/learning-terminal/

Letter and number games for little kids.

Letters

- Phonics: hear a letter sound, then pick the letter. Starts from S A T P I N.

Phonics has an Easy, Medium, or Harder level. The stars on its button match that level.

Numbers

- Counting
- Hear a number
- Which bigger?
- Adding

Choose how many questions to play. The last menu is remembered on this device.

Letter sounds from [Buzzphonics](https://github.com/hellodeborahuk/buzzphonics) (MIT).
Spoken numbers are synthetic, made with [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) (Apache 2.0). See vendor-credits.

Tests: `npm ci` then `npm test`.
